# Changelog

All notable changes to this project are documented here, following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2026-09-14

### Added

- Web registration, login, and independent private financial workspaces.
- Monthly planning, accounts and spaces, income, commitments, provisions, allocations, and historical snapshots.
- Financing records, investment movements, and manual valuations.
- Financial JSON export and validated, atomic import into an empty workspace.
- Responsive Spanish application and English project website with automatic system theme.
- Docker Compose configurations, environment templates, CI and release-image workflows, project documentation, and MIT license.
